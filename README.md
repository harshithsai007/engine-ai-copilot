# EngineAI: The Cognitive Iron Man Suit for Technical Hiring

[![Live Site](https://img.shields.io/badge/Live-Demo-brightgreen)](https://engine-ai-copilot.vercel.app)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**EngineAI** is the ultimate cognitive enhancement layer for elite engineers. Designed as a "Cognitive Iron Man Suit," it provides real-time, staff-level intelligence during high-stakes technical interviews and system design sessions.

## 🚀 Key Features

- **Undetectable Vision AI**: Real-time screen analysis that interprets complex diagrams, code snippets, and whiteboard problems without triggering security flags.
- **Staff-Level Guidance**: Receive architectural insights, edge-case analysis, and algorithmic optimizations that mirror the thinking of a Principal Engineer.
- **Context-Aware Reasoning**: Deep understanding of project requirements, legacy constraints, and modern best practices.
- **Low-Latency Response**: Built for the speed of live conversation.

## 💻 Installation

### Desktop Co-Pilot (Recommended)

To experience the full power of EngineAI with system-wide integration:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/harshithsai007/engine-ai-copilot.git
   cd engine-ai-copilot
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment**:
   Create a `.env.local` file with your API keys (see `.env.example`).

4. **Launch the Co-Pilot**:
   ```bash
   npm run dev
   ```

## 🛠 Tech Stack

- **Frontend**: Next.js 16 (App Router), Tailwind CSS
- **Backend**: Node.js, Stripe Integration
- **AI Engine**: Custom Vision-Language Models optimized for technical reasoning
